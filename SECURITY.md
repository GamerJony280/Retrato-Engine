# Security

No private reporting channel or long-term security support policy has been
established. Check whether this repository's maintainers have enabled GitHub
private vulnerability reporting before sharing sensitive material publicly.
Do not publish credentials, personal data or an exploit containing private files.

Lua scripts are trusted local code and can use standard libraries. Neither Lua
nor asset readers provide an isolation sandbox. Use an isolated process for
untrusted content. Reports should identify the release, platform, impact and
smallest reproduction without exposing private machine paths or user data.
